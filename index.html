About data storage

This dashboard uses localStorage. There is no account login, tracking service, or cloud synchronization. Using GitHub Pages hosts the website code but does not sync lesson completion across devices. Export/import is your portable backup.

If browser storage is blocked or cleared, unsaved progress may be lost. For the most reliable use, open it from a fixed GitHub Pages URL in the same browser profile.
